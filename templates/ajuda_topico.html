📊 Importação de Dados

Importante: Apenas administradores podem importar dados.
Formatos Suportados:
  • Excel: .xlsx, .xls
  • CSV: .csv (valores separados por vírgula)
Estrutura do Arquivo:

Seu arquivo deve conter as colunas:

  • numero - Número do bem (obrigatório)
  • nome - Nome/descrição do bem (obrigatório)
  • situacao - Situação (Localizado/Pendente)
  • localizacao - Localização atual
  • responsavel - Responsável pelo bem
Passo a Passo:
  1. Clique em "Importar Excel/CSV" na página inicial
  2. Selecione o arquivo
  3. Informe o nome da aba (para Excel)
  4. Escolha se deseja fazer backup
  5. Clique em "Importar"
{% elif topico == 'busca' %}

🔍 Busca e Localização

Como Buscar um Bem:
  1. Digite o número do bem no campo principal
  2. Ou use a câmera para escanear o código de barras
  3. Informe a localização se o bem foi encontrado
  4. Clique em "Buscar" para atualizar
Dicas:
  • O sistema foca automaticamente no campo de busca
  • Use a tecla Enter para buscar rapidamente
  • O scanner funciona melhor com boa iluminação
{% elif topico == 'exportacao' %}

📥 Exportação de Relatórios

Relatórios Disponíveis:
  • Bens Localizados: Todos os bens marcados como localizados
  • Bens Pendentes: Bens ainda não localizados
  • Por Localidade: Bens agrupados por localização
Como Exportar:
  1. Acesse a página desejada (Localizados, Pendentes ou Localidades)
  2. Clique no botão "Exportar" correspondente
  3. O arquivo Excel será baixado automaticamente
{% elif topico == 'scanner' %}

📷 Uso do Scanner

Atenção: O scanner requer permissão de câmera.
Como Usar:
  1. Clique no ícone da câmera ao lado do campo de busca
  2. Permita o acesso à câmera quando solicitado
  3. Posicione o código de barras dentro do quadro
  4. O sistema detectará automaticamente
  5. Clique em "Usar" para inserir o código
Problemas Comuns:
  • Câmera não funciona: Verifique as permissões do navegador
  • Não detecta código: Melhore a iluminação e aproxime a câmera
  • Qualidade ruim: Limpe a lente da câmera
{% elif topico == 'cadastro' %}

➕ Cadastro de Bens

Como Cadastrar:
  1. Acesse "Gestão Completa" no menu
  2. Clique em "Novo Bem"
  3. Preencha os dados obrigatórios:
    • Número do bem
    • Nome/descrição
  4. Preencha os dados opcionais se desejar
  5. Clique em "Salvar"
Dados do Bem:
  • Número: Identificador único (não pode repetir)
  • Nome: Descrição do bem patrimonial
  • Situação: Localizado ou Pendente
  • Localização: Onde o bem se encontra
  • Responsável: Pessoa responsável pelo bem
