📝 Cadastro de Bens

Dica importante: Mantenha os dados dos bens sempre atualizados para um controle patrimonial eficiente.

Como Cadastrar um Novo Bem

1
Acesse o formulário de cadastro

Clique em "Novo Bem" no menu superior ou acesse através do "Sistema CRUD" → botão "Novo Bem".

2
Preencha os dados obrigatórios

Informe os campos essenciais marcados com *:

  • Número do Bem: Código único (ex: "PT-001", "COMP-2024-001")
  • Nome do Bem: Descrição completa do item
O número do bem deve ser único no sistema!
3
Complete com informações adicionais

Preencha os campos opcionais para um cadastro mais completo:

  • Localização: Onde o bem está instalado
  • Responsável: Pessoa encarregada
  • Auditor: Responsável pela vistoria
  • Data Última Vistoria: Última verificação
  • Data Vistoria Atual: Verificação em curso
  • Observações: Informações complementares
4
Salve o cadastro

Clique em para finalizar o cadastro.

Sucesso! O bem será cadastrado e aparecerá na lista geral do sistema.

📍 Sistema de Localização

Use este sistema para marcar bens como localizados durante vistorias e inventários.

Localizando um Bem

1
Busque pelo número

Na página inicial, digite o número do bem no campo de busca:

Exemplo: PT-001, COMP-2024-001, MOB-003
2
Confirme a localização

O sistema mostrará a localização atual. Se necessário, informe uma nova localização:

Exemplos de localização:
"Sala 101 - Departamento TI"
"Almoxarifado - Prateleira A3"
"Recepção - Balcão Principal"
3
Marque como localizado

Clique em para confirmar.

O sistema atualizará automaticamente o status do bem para Localizado.

Como Gerar Relatórios

1
Acesse a visualização desejada

No menu principal, clique em "Visualizar" e escolha o tipo de relatório:

  • Bens Localizados: Itens confirmados
  • Bens Não Localizados: Itens pendentes
Use os filtros para refinar sua busca antes de exportar
2
Exporte para Excel

Na página de visualização, clique no botão

O arquivo será gerado automaticamente com:

  • Timestamp no nome do arquivo
  • Dados organizados em colunas
  • Formatação profissional
  • Ordenação por número do bem
Exemplo de nome:
bens_localizados_20241201-143022.xlsx
3
Relatório por Localidade

Para relatórios específicos por localização:

  1. Acesse "Relatório por Localidade"
  2. Selecione a localidade desejada no dropdown
  3. Use os filtros de situação se necessário
  4. Clique em

📤 Importação de Dados

Atenção: A importação substitui dados existentes. Sempre faça backup antes de importar.

Preparando sua Planilha

1
Estrutura da Planilha

Sua planilha Excel deve conter estas colunas na primeira linha:

Coluna Obrigatória Tipo Exemplo
numero Texto PT-001, COMP-001
nome Texto Computador Dell
situacao (opcional) Texto OK, Pendente
localizacao (opcional) Texto Sala 101
2
Formato do Arquivo
✅ Formatos Suportados
  • .xlsx (Excel 2007+)
  • .xls (Excel 97-2003)
❌ Formatos Não Suportados
  • .csv
  • .pdf
  • .ods

Processo de Importação

1
Acesse a ferramenta de importação

Na página inicial, role até a seção "Importar do Excel"

2
Configure a importação
  • Arquivo Excel: Selecione seu arquivo
  • Nome da Aba: Geralmente "Estoque"
  • Backup: Recomendado marcar esta opção
Backup automático: O sistema cria uma cópia de segurança antes da importação.
3
Execute a importação

Clique em

O sistema validará a estrutura do arquivo e importará os dados. Você receberá um relatório completo do processo.

Validações Realizadas

Validações de Estrutura
  • Formato do arquivo
  • Existência da aba especificada
  • Colunas obrigatórias presentes
  • Tipos de dados básicos
Validações de Dados
  • Números de bem duplicados
  • Campos obrigatórios preenchidos
  • Formato de datas
  • Consistência das informações

🛠️ Solução de Problemas

Encontre soluções rápidas para os problemas mais comuns. Se não encontrar sua resposta, entre em contato com o suporte.

Problemas Frequentes

Problema: "Bem não encontrado" ao tentar localizar

Sintoma: Digito o número do bem mas o sistema diz que não foi encontrado.

Solução
  1. Verifique o número digitado
    • Confirme se não há espaços extras
    • Verifique letras maiúsculas/minúsculas
    • Confirme caracteres especiais
  2. Verifique se o bem está cadastrado
    • Acesse "Sistema CRUD"
    • Busque pelo número do bem
    • Verifique se existe na lista
  3. Use a busca avançada
    • Vá em "Buscar" no menu
    • Digite parte do nome
    • Verifique resultados similares
Problema: Erro ao importar arquivo Excel

Sintoma: Recebo mensagem de erro ao tentar importar dados do Excel.

Solução
Verifique o arquivo:
  • Formato: .xlsx ou .xls
  • Aba: Nome correto da planilha
  • Colunas: Estrutura correta
  • Dados: Sem fórmulas complexas
Ações corretivas:
  • Salve como .xlsx se for .xls
  • Verifique o nome da aba
  • Confirme as colunas obrigatórias
  • Teste com arquivo de exemplo
Problema: Sistema lento ou travando

Sintoma: O sistema está respondendo lentamente ou congelando.

Solução
  1. Limpe o cache do navegador
    • Ctrl+F5 para recarregar forçado
    • Limpe cache e cookies
  2. Verifique a conexão
    • Teste sua internet
    • Verifique se o servidor está online
  3. Otimize os dados
    • Exporte e remova dados antigos
    • Use filtros nas visualizações
Problema: Não consigo editar um bem

Sintoma: Clico em editar mas não carrega os dados ou dá erro.

Solução
Verificações rápidas:
  • Recarregue a página (F5)
  • Verifique o console do navegador (F12)
  • Teste em outro navegador
Soluções avançadas:
  • Verifique se o JavaScript está habilitado
  • Desative extensões do navegador
  • Clear storage do site

Ferramentas de Diagnóstico

Console do Navegador

Pressione F12 e verifique a aba "Console" para mensagens de erro detalhadas.

Teste de Conexão

Verifique se há problemas de rede ou com o servidor.
